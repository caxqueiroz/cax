# Plan 9: Hooks — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `internal/hooks`, a Claude-Code-compatible declarative shell-command dispatcher for the four events `UserPromptSubmit` / `PreToolUse` / `PostToolUse` / `Stop`, and wire it into `internal/agent/hooks.go` so plugin-contributed hooks block turns / tool calls (best-effort, JSON envelope on stdin, exit != 0 = block with stdout as feedback, 5s default timeout, SIGKILL on hang), exposing live entries through `channel.Status.HookCount` and a `/hooks` slash command.

**Architecture:** `hooks.Dispatcher` holds a `[]hooks.Entry` (one per plugin-declared hook) and an `*slog.Logger`. `Dispatch(ctx, ev, payload)` filters entries by `Event` + `Matcher` (Tool exact / case-insensitive; Command substring; empty matcher = match all of that event), then for each match runs `exec.CommandContext` with a JSON envelope on stdin, captures stdout (trimmed → `Feedback`), and treats exit 0 as no-block, anything else as block. A per-entry timer (default 5s) cancels the context and `Process.Kill`s the child if it overruns; spawn errors / non-exit failures are logged + skipped (best-effort, never propagated to the agent). Wiring: existing `hookDeps.preGeneration` calls `Dispatch(EventUserPromptSubmit, …)` first and returns the feedback as a `dive.HookAbortError` on block (aborts the turn before memory injection runs); `hookDeps.preToolUse` calls `Dispatch(EventPreToolUse, …)` BEFORE the existing permission gate and returns `dive.NewUserFeedback(feedback)` on block so dive surfaces the feedback to the model; `hookDeps.postGeneration` calls `Dispatch(EventStop, …)` informationally (feedback logged, never blocks). Dive v1.7 exposes a discrete `PostToolUseHook` (verified in `$(go env GOMODCACHE)/github.com/deepnoodle-ai/dive@v1.7.0/hooks.go`), so a new `hookDeps.postToolUse` calls `Dispatch(EventPostToolUse, …)` and surfaces feedback via `hctx.AdditionalContext` (no blocking — Claude Code's PostToolUse can't block either). `cmd/czcli/main.go` converts `plugins.Contributions.Hooks` ([]plugins.HookEntry) → []hooks.Entry, builds the dispatcher, and passes it into `agent.Build` / `agent.Rebuild` so hot-reload (Plan 7's `/plugin` mutations) swaps the entry set under the agent's mutex. `channel.Status.HookCount` is populated from `len(dispatcher.Entries())` inside `Assistant.Status`; `/hooks` lists entries as `event · matcher · plugin · timeout`.

**Tech Stack:** Go 1.25, `os/exec` (`CommandContext` + `Process.Kill`), `encoding/json` (envelope), `context` (timeout), `log/slog` (best-effort logging), `github.com/deepnoodle-ai/dive` v1.7.0 (`HookAbortError`, `NewUserFeedback`, `PostToolUseHook`, `HookContext.AdditionalContext`), `github.com/caxqueiroz/czcli/internal/plugins` (`HookEntry`, `Contributions`), `github.com/caxqueiroz/czcli/internal/channel`.

## Research notes (authoritative — verified 2026-05-30)

- **Claude Code 2026 hook payloads** (`https://code.claude.com/docs/en/hooks`). Every event carries a common envelope:
  ```json
  { "session_id": "...", "transcript_path": "...", "cwd": "...",
    "hook_event_name": "EventName", "permission_mode": "default" }
  ```
  Per-event additions used by czcli:
  - `UserPromptSubmit`: `"prompt": "<user text>"`.
  - `PreToolUse`: `"tool_name": "Bash"`, `"tool_input": { ...json... }`.
  - `PostToolUse`: `"tool_name": "Bash"`, `"tool_input": { ... }`, `"tool_output": {"stdout":"...", "stderr":"...", "exit_code":0}`.
  - `Stop`: common-fields-only.
  - **Exit-code gate** (we keep czcli's simpler model: any non-zero = block — Claude Code's exit 2 is a strict subset). Stdout (trimmed UTF-8) → `Result.Feedback`. JSON output objects (`hookSpecificOutput`, `decision`) are NOT parsed in MVP; we treat the whole stdout as text feedback, matching the spec's "stdout = feedback to model". (Tracked in `docs/backlog.md` as a follow-up if a plugin ships JSON-only hooks.)
- **dive v1.7 hook surfaces** (verified in `/Users/cq/go/pkg/mod/github.com/deepnoodle-ai/dive@v1.7.0/hooks.go` and `agent.go`):
  - `type Hooks struct { PreGeneration []PreGenerationHook; PostGeneration []PostGenerationHook; PreToolUse []PreToolUseHook; PostToolUse []PostToolUseHook; PostToolUseFailure []PostToolUseFailureHook; Stop []StopHook; ... }`.
  - `PreGenerationHook func(ctx, *HookContext) error` — returning **any error** aborts the turn; returning `*HookAbortError` is the documented "abort entirely" path. We use `dive.AbortGeneration(feedback)` so the turn is cleanly aborted and the error reaches `Handle`, which emits `channel.StreamEvent{Type:"error", Text: feedback}` and returns the wrapped error to the caller (same path our existing error events use — see `agent.go:152`).
  - `PreToolUseHook func(ctx, *HookContext) error` — returning a `*UserFeedbackError` (via `dive.NewUserFeedback("...")`) is converted by dive into a Deny tool result that is sent to the LLM as the tool's response, so the model can adapt instead of crashing (confirmed by file comment on lines 173–177 + 500–512 of `hooks.go`).
  - `PostToolUseHook func(ctx, *HookContext) error` — runs after a successful tool call; comment "Hook errors are logged but do not affect the tool result" (lines 188–190). `hctx.AdditionalContext` is appended as a text block to the tool result message sent to the LLM (lines 122–125). This is the right channel for PostToolUse feedback.
  - Stop wiring uses the existing `PostGenerationHook` chain (the spec's `EventStop` semantics: "informational only here"). dive v1.7 also has a discrete `StopHook` with a `*StopDecision{Continue, Reason}` return value, but the design pins Stop to `PostGenerationHook` so it fires once per turn at the end — using `StopHook` would re-enter the generation loop on `Continue: true`, which is NOT what Claude-Code-style Stop hooks do.
- **`exec.CommandContext` + hard timeout idiom** (Go stdlib pattern):
  ```go
  ctx, cancel := context.WithTimeout(parent, timeout)
  defer cancel()
  cmd := exec.CommandContext(ctx, entry.Command[0], entry.Command[1:]...)
  cmd.Stdin = bytes.NewReader(envelopeJSON)
  var stdout bytes.Buffer
  cmd.Stdout = &stdout
  err := cmd.Run()
  // ctx.Err() == context.DeadlineExceeded ⇒ CommandContext already SIGKILL'd
  // the child; we log "hook timeout" and treat as no-op (best-effort).
  ```
  `exec.CommandContext` calls `Process.Kill` (SIGKILL on Unix) when the context is cancelled — verified in `os/exec/exec.go` `(*Cmd).Start` watch-goroutine. The timeout test only needs to assert that `Run` returns within ~timeout (and not after `sleep 10` finished).

- **plugins.HookEntry → hooks.Entry conversion** (per `01-extensibility-contracts.md` §Hooks): the `plugins` package owns the JSON parsing (Plan 7) and emits `[]plugins.HookEntry` with `Matcher map[string]string`. Plan 9 owns the typed `hooks.Matcher{Tool, Command string}`. The conversion is a tiny pure function in `cmd/czcli/main.go` (only consumer of both packages today); colocating it there keeps `internal/hooks` from importing `internal/plugins` (avoids a needless dependency since the dispatcher consumes typed Entries only).

```go
// Package hooks runs plugin-declared shell-command hooks on agent lifecycle
// events: UserPromptSubmit, PreToolUse, PostToolUse, Stop. Hooks receive a JSON
// envelope on stdin; their stdout is fed back to the model and their exit code
// is the gate (0 = no block; non-zero = block with stdout as feedback). All
// failures (spawn errors, timeouts, panics) are logged and treated as no-ops so
// a broken hook never blocks the agent — best-effort throughout.
package hooks

// Event identifies an agent lifecycle event a hook can subscribe to. The string
// values match Claude Code's wire format (hook_event_name) so plugin manifests
// authored for Claude Code run unchanged in czcli.
type Event string

const (
	EventUserPromptSubmit Event = "UserPromptSubmit"
	EventPreToolUse       Event = "PreToolUse"
	EventPostToolUse      Event = "PostToolUse"
	EventStop             Event = "Stop"
)

// Matcher narrows when a hook fires. An empty Matcher (zero value) matches all
// events of its configured type. Tool is exact-match (case-insensitive) on the
// tool name; Command is substring on the Bash command string.
type Matcher struct {
	Tool    string
	Command string
}

// Entry is one declared hook: which event, optional matcher, the argv to exec,
// a per-entry timeout (seconds; 0 means use the dispatcher default), and the
// plugin name that contributed it (for the /hooks listing).
type Entry struct {
	Event          Event
	Matcher        Matcher
	Command        []string
	TimeoutSeconds int
	Source         string
}

// Result is the outcome of one Dispatch call. Block is true when at least one
// matching hook exited non-zero; Feedback is the joined stdout of all blocking
// hooks (or empty if none blocked).
type Result struct {
	Block    bool
	Feedback string
}
```

```go
package hooks

import "strings"

// matches reports whether an Entry fires for the given event + tool/command
// pair. An empty Matcher (zero value) matches all events of its configured
// type. Tool is exact-match, case-insensitive. Command is substring (Bash).
// When both Matcher.Tool and Matcher.Command are set, both must hold.
func matches(e Entry, ev Event, toolName, command string) bool {
	if e.Event != ev {
		return false
	}
	if e.Matcher.Tool != "" {
		if !strings.EqualFold(e.Matcher.Tool, toolName) {
			return false
		}
	}
	if e.Matcher.Command != "" {
		if !strings.Contains(command, e.Matcher.Command) {
			return false
		}
	}
	return true
}
```

```go
package hooks

import (
	"context"
	"log/slog"
)

// defaultTimeoutSeconds is applied when an Entry sets TimeoutSeconds <= 0.
// Matches Claude Code's documented default of 5 seconds.
const defaultTimeoutSeconds = 5

// Dispatcher runs plugin-declared hooks for the four lifecycle events. It is
// safe to call methods on a nil *Dispatcher: Dispatch returns a no-op Result
// and Entries returns nil. This keeps wiring in agent.Build trivial when no
// plugins contribute hooks.
type Dispatcher struct {
	entries []Entry
	logger  *slog.Logger
}

// Load constructs a Dispatcher over the given entries. The logger is used for
// best-effort error reporting (spawn failures, timeouts) and must not be nil;
// callers should pass slog.Default() when they have no specific logger.
func Load(entries []Entry, logger *slog.Logger) *Dispatcher {
	if logger == nil {
		logger = slog.Default()
	}
	cp := make([]Entry, len(entries))
	copy(cp, entries)
	return &Dispatcher{entries: cp, logger: logger}
}

// Entries returns the registered hook entries. The returned slice is a copy
// safe for callers to read (e.g. /hooks listing) without mutating dispatcher
// state. nil-safe: returns nil if d is nil.
func (d *Dispatcher) Entries() []Entry {
	if d == nil {
		return nil
	}
	cp := make([]Entry, len(d.entries))
	copy(cp, d.entries)
	return cp
}

// Dispatch runs every entry whose Event + Matcher matches ev and the payload's
// tool/command (extracted internally). It returns Block=true if any matching
// hook exited non-zero, joining their stdout into Feedback. Errors (spawn,
// timeout, non-exit-code failures) are logged and treated as no-ops so a
// broken hook never blocks the agent.
//
// nil-safe: returns a no-op Result if d is nil.
func (d *Dispatcher) Dispatch(ctx context.Context, ev Event, payload any) Result {
	if d == nil || len(d.entries) == 0 {
		return Result{}
	}
	toolName, command := payloadToolCommand(payload)
	var result Result
	for _, e := range d.entries {
		if !matches(e, ev, toolName, command) {
			continue
		}
		r := d.runOne(ctx, e, ev, payload)
		if r.Block {
			result.Block = true
			result.Feedback = joinFeedback(result.Feedback, r.Feedback)
		}
	}
	return result
}

// runOne is implemented in Task 4 — for now it is a no-op so the skeleton tests
// pass. The real implementation execs the hook with a JSON envelope on stdin.
func (d *Dispatcher) runOne(ctx context.Context, e Entry, ev Event, payload any) Result {
	return Result{}
}

// payloadToolCommand extracts tool_name + command from a payload map. Both are
// optional; missing/non-string fields return "". The payload shape mirrors
// Claude Code's hook envelope: {"tool_name": "Bash", "tool_input": {"command": "..."}}.
func payloadToolCommand(payload any) (toolName, command string) {
	m, ok := payload.(map[string]any)
	if !ok {
		return "", ""
	}
	if v, ok := m["tool_name"].(string); ok {
		toolName = v
	}
	if ti, ok := m["tool_input"].(map[string]any); ok {
		if v, ok := ti["command"].(string); ok {
			command = v
		}
	}
	return toolName, command
}

// joinFeedback concatenates non-empty feedback strings with a blank line so the
// model can read multiple blocking hooks' outputs in one Result.Feedback.
func joinFeedback(a, b string) string {
	if a == "" {
		return b
	}
	if b == "" {
		return a
	}
	return a + "\n\n" + b
}
```

```go
import (
	"bytes"
	"context"
	"encoding/json"
	"errors"
	"log/slog"
	"os/exec"
	"strings"
	"time"
)

// runOne executes a single matching Entry. The envelope is JSON-encoded onto
// stdin; stdout is trimmed and returned as Feedback when the child exits
// non-zero. Spawn errors, timeouts, and non-exit-code failures are logged and
// treated as no-ops (best-effort: a broken hook must never block the agent).
func (d *Dispatcher) runOne(ctx context.Context, e Entry, ev Event, payload any) Result {
	if len(e.Command) == 0 {
		d.logger.Warn("hook: empty command, skipping", "event", string(ev), "source", e.Source)
		return Result{}
	}

	envelope, err := buildEnvelope(ev, payload)
	if err != nil {
		d.logger.Warn("hook: failed to build envelope", "event", string(ev), "source", e.Source, "err", err)
		return Result{}
	}

	timeout := time.Duration(e.TimeoutSeconds) * time.Second
	if timeout <= 0 {
		timeout = time.Duration(defaultTimeoutSeconds) * time.Second
	}
	runCtx, cancel := context.WithTimeout(ctx, timeout)
	defer cancel()

	cmd := exec.CommandContext(runCtx, e.Command[0], e.Command[1:]...)
	cmd.Stdin = bytes.NewReader(envelope)
	var stdout, stderr bytes.Buffer
	cmd.Stdout = &stdout
	cmd.Stderr = &stderr

	err = cmd.Run()
	if runCtx.Err() == context.DeadlineExceeded {
		d.logger.Warn("hook: timeout, killed", "event", string(ev), "source", e.Source, "timeout", timeout)
		return Result{}
	}
	if err == nil {
		return Result{} // exit 0 = no block
	}

	var exitErr *exec.ExitError
	if errors.As(err, &exitErr) {
		// Non-zero exit blocks; stdout is the feedback the model sees.
		feedback := strings.TrimSpace(stdout.String())
		if feedback == "" {
			feedback = strings.TrimSpace(stderr.String())
		}
		return Result{Block: true, Feedback: feedback}
	}

	// Spawn errors and other non-exit-code failures: log and skip.
	d.logger.Warn("hook: exec failed", "event", string(ev), "source", e.Source, "err", err)
	return Result{}
}

// buildEnvelope renders the JSON object written to a hook's stdin. The shape
// mirrors Claude Code's hook envelope so plugins authored for Claude Code work
// in czcli: a base {hook_event_name, ...} merged with any payload-supplied
// fields (e.g. tool_name, tool_input, prompt).
func buildEnvelope(ev Event, payload any) ([]byte, error) {
	env := map[string]any{
		"hook_event_name": string(ev),
	}
	if m, ok := payload.(map[string]any); ok {
		for k, v := range m {
			env[k] = v
		}
	}
	return json.Marshal(env)
}
```

```go
import (
```

```go
// contribsToHookEntries converts plugins.HookEntry (string Event + map matcher,
// used in the JSON manifests) into the typed hooks.Entry the dispatcher
// consumes. Unknown event names are skipped + logged.
func contribsToHookEntries(in []plugins.HookEntry, logger *slog.Logger) []hooks.Entry {
	out := make([]hooks.Entry, 0, len(in))
	for _, h := range in {
		ev := hooks.Event(h.Event)
		switch ev {
		case hooks.EventUserPromptSubmit, hooks.EventPreToolUse,
			hooks.EventPostToolUse, hooks.EventStop:
			// ok
		default:
			logger.Warn("hooks: unknown event in plugin manifest, skipping",
				"event", h.Event, "source", h.Source)
			continue
		}
		out = append(out, hooks.Entry{
			Event:          ev,
			Matcher:        hooks.Matcher{Tool: h.Matcher["tool"], Command: h.Matcher["command"]},
			Command:        h.Command,
			TimeoutSeconds: h.TimeoutSeconds,
			Source:         h.Source,
		})
	}
	return out
}
```
