# Plan 8: LSP — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `internal/lsp`, a manager that spawns one Language Server Protocol child per configured `LSPServerConfig` over stdio JSON-RPC2, performs the `initialize`/`initialized` handshake, tracks per-file `didOpen`/`didClose` lifecycle plus the most recent `textDocument/publishDiagnostics` notification per URI, and exposes six generic `dive.FuncTool`s (`lsp_definition`, `lsp_references`, `lsp_hover`, `lsp_document_symbols`, `lsp_workspace_symbols`, `lsp_diagnostics`) routed by file-extension → language → server. User-config `LSPConfig.Servers` plus plugin-contributed servers feed the same `New(ctx, servers, rootDir)` constructor; the manager is wired into `agent.Build` via the extended Plan 6 signature, populates `channel.Status.LSPServerCount`/`LSPLanguages`, and is surfaced by `/lsp`.

**Architecture:** `lsp.Manager` owns a `map[string]*server` keyed by language (each `server` wraps the child `*exec.Cmd`, a `jsonrpc2.Conn` over `jsonrpc2.NewStream(stdio)`, and a guarded `map[uri]bool` of currently-open files plus `map[uri][]protocol.Diagnostic` of cached diagnostics). Each spawned server is brought up to the `initialized` state inside `New`; failures per server are logged and surfaced via `ServerInfo.LastError` (others continue). Each `dive.FuncTool` (constructed by `Tools()`) resolves the file argument → extension → language via the default extension map (or `LSPServerConfig.Languages`), ensures the file is `didOpen`'ed on its server, issues the LSP request with a 10s per-request deadline, formats the response into a human-readable string, and returns `dive.NewToolResultText(...)`. Files outside any mapping or with no running server return a "no LSP server for X" tool result so the model adapts. `Close()` sends `shutdown`+`exit` and reaps each child. Tests are offline: an in-process `net.Pipe()` hosts a fake `jsonrpc2.Conn` server that answers `initialize`+each method via a `jsonrpc2.Handler`; no real language-server binaries are spawned.

**Tech Stack:** Go 1.25, `go.lsp.dev/protocol@v0.12.0`, `go.lsp.dev/jsonrpc2@v0.10.0` (both BSD-3-Clause, latest tagged on `github.com/go-language-server/*`, contract-named defaults), `os/exec`, `net.Pipe`, `github.com/deepnoodle-ai/dive` (FuncTool + tool result helpers), existing `internal/config`, `internal/agent`, `internal/channel/cli`.

## Research notes (authoritative — verified 2026-05-30)

- **Library choice — `go.lsp.dev/protocol` + `go.lsp.dev/jsonrpc2`.** Compared to `github.com/sourcegraph/go-lsp` (types only, no live transport) and `github.com/tliron/glsp` (server-side framework, no client API), `go.lsp.dev/*` ships both protocol types and the client-side `jsonrpc2.Conn`/`Stream` pair, is the contract's default, and is what `gopls`-friendly LSP clients in the Go ecosystem use (113 importers on `jsonrpc2`, 165 on `protocol` per pkg.go.dev). Tags are pre-`v1` but stable for years: `protocol@v0.12.0` (2024-03-23) and `jsonrpc2@v0.10.0` (2022-03-23). Pin those versions.
- **`go.lsp.dev/jsonrpc2@v0.10.0` API surface (from pkg.go.dev):**
  - `Stream` interface: `Read(ctx) (Message, int64, error)` / `Write(ctx, Message) (int64, error)` / `Close() error`.
  - `NewStream(conn io.ReadWriteCloser) Stream` — wraps an `io.ReadWriteCloser` with the LSP `Content-Length:`/MIME framing.
  - `Conn` interface: `Call(ctx, method, params, result) (ID, error)`, `Notify(ctx, method, params) error`, `Go(ctx, Handler)`, `Close() error`, `Done() <-chan struct{}`, `Err() error`.
  - `NewConn(s Stream) Conn` — builds a connection over a Stream.
  - `Handler func(ctx context.Context, reply Replier, req Request) error` / `Replier func(ctx, result, err) error`. We pass a handler to `conn.Go(ctx, handler)` to receive server-initiated notifications (specifically `textDocument/publishDiagnostics`).
- **`go.lsp.dev/protocol@v0.12.0` API surface (from pkg.go.dev):**
  - Method-name constants we use: `MethodInitialize`, `MethodInitialized`, `MethodShutdown`, `MethodExit`, `MethodTextDocumentDidOpen`, `MethodTextDocumentDidClose`, `MethodTextDocumentDefinition`, `MethodTextDocumentReferences`, `MethodTextDocumentHover`, `MethodTextDocumentDocumentSymbol`, `MethodWorkspaceSymbol`, `MethodTextDocumentPublishDiagnostics`.
  - Concrete request/response Go types we use: `InitializeParams`/`InitializeResult`, `InitializedParams`, `DidOpenTextDocumentParams` (carries a `TextDocumentItem{URI, LanguageID, Version, Text}`), `DidCloseTextDocumentParams`, `DefinitionParams` (embeds `TextDocumentPositionParams`), `ReferenceParams` (embeds `TextDocumentPositionParams`, has `Context ReferenceContext{IncludeDeclaration: true}`), `HoverParams`, `DocumentSymbolParams`, `WorkspaceSymbolParams{Query string}`, `PublishDiagnosticsParams{URI, Diagnostics}`. Result types include `Location`/`[]Location`, `Hover{Contents}`, `[]DocumentSymbol` (or `[]SymbolInformation` — gopls returns `[]DocumentSymbol`; we accept `json.RawMessage` and try both), `[]SymbolInformation`, `Diagnostic`. `Position{Line, Character uint32}`, `Range{Start, End Position}`, `TextDocumentIdentifier{URI uri.URI}`. `WorkspaceFolder{URI string, Name string}` in `InitializeParams.WorkspaceFolders` (`[]WorkspaceFolder`).
  - `uri.URI` is a string newtype; build with `uri.File(absPath)` (re-exported from `go.lsp.dev/uri`). We always pass absolute paths.
- **Stdio LSP spawning (concrete pattern):** `cmd := exec.CommandContext(ctx, command, args...); stdin, _ := cmd.StdinPipe(); stdout, _ := cmd.StdoutPipe(); cmd.Stderr = os.Stderr; cmd.Start()`, then wrap with a tiny `stdio{stdin io.WriteCloser; stdout io.ReadCloser}` `io.ReadWriteCloser` shim and pass to `jsonrpc2.NewStream(...)`. Both pipes implement the right halves; the shim's `Close()` closes both.
- **In-process fake server (no child process, deterministic):** `clientSide, serverSide := net.Pipe()` produces a synchronous bidi `net.Conn` pair. We wrap *both* sides as `jsonrpc2.NewStream(side)` and create two `jsonrpc2.Conn`s with `NewConn`. The test installs a `jsonrpc2.Handler` on the server side that branches on `req.Method()` (a string) and either calls `reply(ctx, <result>, nil)` for requests, or sends a notification via `serverConn.Notify(ctx, MethodTextDocumentPublishDiagnostics, params)` to drive the manager's notification handler. `net.Pipe()` connections are synchronous — there is no time-dependence, no real sockets, no timing flakiness. Both connections are closed at test cleanup. This is the same pattern documented for `go.lsp.dev/jsonrpc2` LSP clients.
- **Contract mismatch / adaptation:** the contract sketches a `Server struct{ Name, Cmd string; Args, Languages, RootPatterns []string; client *jsonrpc2.Conn }`. The library's connection type is the `jsonrpc2.Conn` *interface* (not a pointer to a struct), so we use `conn jsonrpc2.Conn` (interface value). The exported `Manager`, `ServerInfo`, `New`, `Tools`, `Close` signatures stay verbatim. The contract names `lsp_*` tools and the default extension map verbatim — both used as-is. The contract's `ServerInfo` has `Languages []string` (server-level); since each server is keyed by language inside the manager, we emit one `ServerInfo` per configured `LSPServerConfig` (so a multi-language server lists all its languages in one entry).
- **Routing rule (contract verbatim):** file extension → language → server. Default map: `.go→go .py→python .ts→typescript .tsx→typescript .js→javascript .jsx→javascript .rs→rust .rb→ruby .java→java .c→c .cpp→cpp .h→c .hpp→cpp .cs→csharp .php→php .lua→lua .yaml→yaml .yml→yaml .json→json .md→markdown`. Per-server `LSPServerConfig.Languages` adds (or overrides) the language set the server claims; the manager registers `lang → server` for each language the server lists. Duplicate language → first wins (deterministic by config order); a warning is logged.

package lsp

import (
	"context"
	"sync"

	"github.com/caxqueiroz/czcli/internal/config"
	"go.lsp.dev/jsonrpc2"
)

// ServerInfo is the per-server snapshot reported by New and surfaced via
// /lsp + channel.Status. Names + fields are contract-fixed.
type ServerInfo struct {
	Name      string
	Languages []string
	Running   bool
	LastError string
}

// server is the live state for one spawned LSP child.
type server struct {
	name      string
	languages []string
	conn      jsonrpc2.Conn

	mu          sync.Mutex
	openFiles   map[string]bool                 // uri -> open
	diagnostics map[string]any                  // uri -> []protocol.Diagnostic (any for Task 1 stub)
	closeFn     func() error                    // shuts down conn + reaps child
}

// Manager owns the per-language server map and exposes generic LSP tools.
type Manager struct {
	rootDir string

	mu      sync.Mutex
	servers map[string]*server // language -> server
	all     []*server          // for Close (each server appears once)
}

// New spawns one LSP child per server config, performs the initialize/
// initialized handshake, and registers each by its claimed languages. Errors
// per server are logged + recorded in ServerInfo.LastError; others continue.
func New(ctx context.Context, servers []config.LSPServerConfig, rootDir string) (*Manager, []ServerInfo, error) {
	m := &Manager{
		rootDir: rootDir,
		servers: make(map[string]*server),
	}
	infos := make([]ServerInfo, 0, len(servers))
	for _, sc := range servers {
		info := ServerInfo{Name: sc.Name, Languages: sc.Languages}
		// Task 3 fills spawn + handshake; for now treat unconnected.
		infos = append(infos, info)
	}
	return m, infos, nil
}

// Close shuts down each server (best-effort). Errors are joined.
func (m *Manager) Close() error {
	m.mu.Lock()
	defer m.mu.Unlock()
	var firstErr error
	for _, s := range m.all {
		if s.closeFn == nil {
			continue
		}
		if err := s.closeFn(); err != nil && firstErr == nil {
			firstErr = err
		}
	}
	m.servers = nil
	m.all = nil
	return firstErr
}
```

import (
	"context"
	"encoding/json"
	"net"
	"testing"
	"time"

	"go.lsp.dev/jsonrpc2"
	"go.lsp.dev/protocol"
)

// fakeServer is the test-side of an in-process LSP connection. It uses net.Pipe
// to back a bi-directional Stream pair, hosts a jsonrpc2 Handler that branches
// on method name, and exposes a Notify hook so tests can simulate
// publishDiagnostics. Closing it tears down both ends.
type fakeServer struct {
	clientConn jsonrpc2.Conn // manager side
	serverConn jsonrpc2.Conn // fake side
	cancel     context.CancelFunc
}

// newFakeServer wires a net.Pipe + two jsonrpc2.Conns and starts both. handler
// is invoked for every request from the manager side. Tests typically branch
// on req.Method() (a string) and reply with reply(ctx, <result>, nil).
func newFakeServer(t *testing.T, handler jsonrpc2.Handler) *fakeServer {
	t.Helper()
	a, b := net.Pipe()
	clientConn := jsonrpc2.NewConn(jsonrpc2.NewStream(a))
	serverConn := jsonrpc2.NewConn(jsonrpc2.NewStream(b))

	ctx, cancel := context.WithCancel(context.Background())
	// The fake (server side) handles requests from the manager.
	serverConn.Go(ctx, handler)
	// The client side needs *some* handler to drain server-initiated
	// notifications; tests override this when they want to capture them.
	clientConn.Go(ctx, func(ctx context.Context, reply jsonrpc2.Replier, req jsonrpc2.Request) error {
		return reply(ctx, nil, nil)
	})

	t.Cleanup(func() {
		cancel()
		_ = clientConn.Close()
		_ = serverConn.Close()
	})
	return &fakeServer{clientConn: clientConn, serverConn: serverConn, cancel: cancel}
}

func TestFakeServerInitializeRoundTrip(t *testing.T) {
	handler := func(ctx context.Context, reply jsonrpc2.Replier, req jsonrpc2.Request) error {
		switch req.Method() {
		case protocol.MethodInitialize:
			return reply(ctx, &protocol.InitializeResult{}, nil)
		default:
			return reply(ctx, nil, nil)
		}
	}
	fs := newFakeServer(t, handler)

	ctx, cancel := context.WithTimeout(context.Background(), 2*time.Second)
	defer cancel()

	var result protocol.InitializeResult
	if _, err := fs.clientConn.Call(ctx, protocol.MethodInitialize, &protocol.InitializeParams{
		RootURI: "file:///",
	}, &result); err != nil {
		t.Fatalf("Call initialize: %v", err)
	}
	// Cover encoding compatibility: serializing the params must round-trip cleanly.
	_, err := json.Marshal(&protocol.InitializeParams{})
	if err != nil {
		t.Fatalf("Marshal InitializeParams: %v", err)
	}
}
```

type server struct {

	conn      jsonrpc2.Conn

	mu          sync.Mutex

	diagnostics map[string][]protocol.Diagnostic

// bringUp dials, handshakes, and registers each configured server. Per-server
// errors are recorded in the returned ServerInfo; bringUp itself returns nil
// unless something catastrophic (nil dialFn) prevents any attempt.
func (m *Manager) bringUp(ctx context.Context, servers []config.LSPServerConfig) ([]ServerInfo, error) {
	if m.dialFn == nil {
		return nil, fmt.Errorf("lsp: dialFn is nil")
	}
	infos := make([]ServerInfo, 0, len(servers))
	for _, sc := range servers {
		info := ServerInfo{Name: sc.Name, Languages: sc.Languages}
		conn, closeFn, err := m.dialFn(ctx, sc)
		if err != nil {
			info.LastError = err.Error()
			slog.Warn("lsp: dial failed", "server", sc.Name, "error", err)
			infos = append(infos, info)
			continue
		}
		s := &server{
			name:        sc.Name,
			languages:   sc.Languages,
			conn:        conn,
			openFiles:   make(map[string]bool),
			diagnostics: make(map[string][]protocol.Diagnostic),
			closeFn:     closeFn,
		}
		// Install the notification handler BEFORE initialize, so that
		// publishDiagnostics arriving immediately after `initialized` are
		// captured. The handler captures s by reference.
		conn.Go(ctx, m.notifyHandler(s))
		if err := m.handshake(ctx, s); err != nil {
			info.LastError = err.Error()
			slog.Warn("lsp: handshake failed", "server", sc.Name, "error", err)
			_ = closeFn()
			infos = append(infos, info)
			continue
		}
		info.Running = true
		m.mu.Lock()
		m.all = append(m.all, s)
		for _, lang := range sc.Languages {
			if _, exists := m.servers[lang]; exists {
				slog.Warn("lsp: duplicate language; ignoring later server", "language", lang, "server", sc.Name)
				continue
			}
			m.servers[lang] = s
		}
		m.mu.Unlock()
		infos = append(infos, info)
	}
	return infos, nil
}

// handshake performs initialize + initialized. WorkspaceFolders carries the
// configured rootDir as a file:// URI.
func (m *Manager) handshake(ctx context.Context, s *server) error {
	rootURI := string(uri.File(m.rootDir))
	var result protocol.InitializeResult
	if _, err := s.conn.Call(ctx, protocol.MethodInitialize, &protocol.InitializeParams{
		RootURI: uri.URI(rootURI),
		WorkspaceFolders: []protocol.WorkspaceFolder{{
			URI:  rootURI,
			Name: "czcli-root",
		}},
		Capabilities: protocol.ClientCapabilities{
			TextDocument: &protocol.TextDocumentClientCapabilities{
				Definition:     &protocol.DefinitionTextDocumentClientCapabilities{},
				References:     &protocol.ReferencesTextDocumentClientCapabilities{},
				Hover:          &protocol.HoverTextDocumentClientCapabilities{},
				DocumentSymbol: &protocol.DocumentSymbolClientCapabilities{},
				PublishDiagnostics: &protocol.PublishDiagnosticsClientCapabilities{
					RelatedInformation: true,
				},
			},
			Workspace: &protocol.WorkspaceClientCapabilities{
				Symbol: &protocol.WorkspaceSymbolClientCapabilities{},
			},
		},
	}, &result); err != nil {
		return fmt.Errorf("initialize: %w", err)
	}
	if err := s.conn.Notify(ctx, protocol.MethodInitialized, &protocol.InitializedParams{}); err != nil {
		return fmt.Errorf("initialized: %w", err)
	}
	return nil
}

// notifyHandler is the jsonrpc2 Handler installed on each server connection:
// it captures publishDiagnostics into the server's cache and ignores other
// server-initiated messages.
func (m *Manager) notifyHandler(s *server) jsonrpc2.Handler {
	return func(ctx context.Context, reply jsonrpc2.Replier, req jsonrpc2.Request) error {
		if req.Method() == protocol.MethodTextDocumentPublishDiagnostics {
			var p protocol.PublishDiagnosticsParams
			if err := jsonUnmarshal(req.Params(), &p); err == nil {
				s.mu.Lock()
				s.diagnostics[string(p.URI)] = p.Diagnostics
				s.mu.Unlock()
			}
		}
		return reply(ctx, nil, nil)
	}
}

// jsonUnmarshal is a tiny indirection so tests can replace it if needed.
// Today it just calls encoding/json.
var jsonUnmarshal = func(data []byte, v any) error { return jsonStdUnmarshal(data, v) }

// dialStdio is the production dialFunc: spawn command+args, wire stdio to a
// jsonrpc2 Stream/Conn, and return a closeFn that closes the conn and reaps
// the child.
func dialStdio(ctx context.Context, sc config.LSPServerConfig) (jsonrpc2.Conn, func() error, error) {
	cmd := exec.CommandContext(ctx, sc.Command, sc.Args...)
	stdin, err := cmd.StdinPipe()
	if err != nil {
		return nil, nil, fmt.Errorf("stdin pipe: %w", err)
	}
	stdout, err := cmd.StdoutPipe()
	if err != nil {
		return nil, nil, fmt.Errorf("stdout pipe: %w", err)
	}
	// Stderr is intentionally drained to a discard pipe; real wiring would
	// stream to slog. Keep it minimal for the MVP.
	cmd.Stderr = io.Discard.(io.Writer)
	if err := cmd.Start(); err != nil {
		return nil, nil, fmt.Errorf("start %s: %w", sc.Command, err)
	}
	rwc := &stdioRWC{r: stdout, w: stdin}
	conn := jsonrpc2.NewConn(jsonrpc2.NewStream(rwc))
	closeFn := func() error {
		_ = conn.Close()
		_ = rwc.Close()
		_ = cmd.Process.Kill()
		_, _ = cmd.Process.Wait()
		return nil
	}
	return conn, closeFn, nil
}

// stdioRWC bridges separate Reader/Writer pipes into an io.ReadWriteCloser
// for jsonrpc2.NewStream.
type stdioRWC struct {
	r io.ReadCloser
	w io.WriteCloser
}

func (s *stdioRWC) Read(p []byte) (int, error)  { return s.r.Read(p) }
func (s *stdioRWC) Write(p []byte) (int, error) { return s.w.Write(p) }
func (s *stdioRWC) Close() error {
	_ = s.r.Close()
	_ = s.w.Close()
	return nil
}

package lsp

import (
	"context"
	"fmt"
	"os"

	"go.lsp.dev/protocol"
	"go.lsp.dev/uri"
)

// ensureOpen sends a textDocument/didOpen notification for path on s, unless
// the file is already tracked as open. It always uses the file's CURRENT
// on-disk text (czcli does not buffer edits between turns).
func (m *Manager) ensureOpen(ctx context.Context, s *server, path string) error {
	u := string(uri.File(path))
	s.mu.Lock()
	if s.openFiles[u] {
		s.mu.Unlock()
		return nil
	}
	s.openFiles[u] = true
	s.mu.Unlock()

	text, err := os.ReadFile(path)
	if err != nil {
		s.mu.Lock()
		delete(s.openFiles, u)
		s.mu.Unlock()
		return fmt.Errorf("read %s: %w", path, err)
	}
	lang := languageFor(path)
	return s.conn.Notify(ctx, protocol.MethodTextDocumentDidOpen, &protocol.DidOpenTextDocumentParams{
		TextDocument: protocol.TextDocumentItem{
			URI:        uri.URI(u),
			LanguageID: protocol.LanguageIdentifier(lang),
			Version:    1,
			Text:       string(text),
		},
	})
}

// closeFile sends textDocument/didClose and clears the open-file flag.
func (m *Manager) closeFile(ctx context.Context, s *server, path string) error {
	u := string(uri.File(path))
	s.mu.Lock()
	if !s.openFiles[u] {
		s.mu.Unlock()
		return nil
	}
	delete(s.openFiles, u)
	s.mu.Unlock()
	return s.conn.Notify(ctx, protocol.MethodTextDocumentDidClose, &protocol.DidCloseTextDocumentParams{
		TextDocument: protocol.TextDocumentIdentifier{URI: uri.URI(u)},
	})
}

// routeServer picks the server registered for the file's language, or returns
// (nil, lang, false) if no server is available. lang is "" if the extension
// has no default mapping.
func (m *Manager) routeServer(path string) (*server, string, bool) {
	lang := languageFor(path)
	if lang == "" {
		return nil, "", false
	}
	m.mu.Lock()
	defer m.mu.Unlock()
	s, ok := m.servers[lang]
	return s, lang, ok
}
